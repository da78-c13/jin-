# 浙江金华科贸职业技术学院 - 自动抢课工具

基于 [wolverine396/qiangke](https://github.com/wolverine396/qiangke) 改造，适配本校正方教务系统 v9.0。

## 功能

- 🌐 **网页配置** — 浏览器填写信息，无需改代码
- 🔐 自动登录教务系统（支持 RSA 加密密码）
- 👀 监控指定课程的剩余名额，发现空位立即自动抢课
- ⏰ 定时启动 — 设置好时间到点自动开抢
- 🔄 智能等待 — 选课未开放时自动等待，开放后高频抢课
- 📧 邮件通知（可选）
- 📝 详细日志记录

## 环境要求

- Python 3.8+
- 网络连接

## 🚀 快速开始（推荐：网页配置）

### 第1步：安装依赖

```bash
cd qiangke_zjjhkm
pip install -r requirements.txt
```

### 第2步：启动配置工具

```bash
python config_web.py
```

浏览器会自动打开配置页面 `http://localhost:8080`，你会看到：

| 卡片 | 填什么 |
|------|--------|
| 🔐 个人信息 | 你的 **学号** 和 **教务系统密码** |
| 📋 抢课列表 | 添加要抢的 **课程名称 + 课程ID**（支持增删） |
| ⏰ 定时设置 | 选课开放时间（如 `12:30`）和监控间隔 |

填完后点击 **💾 保存配置**，所有信息会自动保存到本地文件。

### 第3步：开始抢课

```bash
python main.py
```

程序会显示倒计时，到点自动登录并开抢！

## ⚙️ 手动配置（不打开网页）

如果不方便用网页工具，也可以直接编辑文件：

### 1. 编辑 `.env` 文件

```ini
STUDENT_ID=你的学号
STUDENT_PASSWORD=你的密码
SCHEDULED_START=12:30      # 选课开放时间
MONITOR_INTERVAL=5          # 监控间隔（秒）
```

### 2. 编辑 `courses.json` 添加课程

```json
[
    {"name": "课程名称1", "id": "课程ID1"},
    {"name": "课程名称2", "id": "课程ID2"}
]
```

### 3. 运行

```bash
python main.py
```

## 📖 如何获取课程ID

1. 浏览器打开教务系统并登录：https://jwxt.zjjhkm.edu.cn/jwglxt/
2. 进入选课界面
3. 按 **F12** 打开开发者工具
4. 切换到 **Network（网络）** 标签
5. 在选课页面中选择一门课程
6. 在网络请求中找到包含课程信息的请求
7. 从请求参数或响应中获取 **课程ID**

## ⏰ 定时启动说明

在配置页面设置 `定时启动时间`，支持两种格式：

| 格式 | 示例 | 说明 |
|------|------|------|
| `HH:MM` | `12:30` | 今天没到就今天启动，过了就明天 |
| `YYYY-MM-DD HH:MM` | `2025-09-23 12:30` | 指定具体日期时间 |

- 程序会 **提前30秒自动登录**，到点直接开抢
- 留空则立即启动监控

## 🛠 故障排除

### 登录失败
1. 检查 `.env` 中的学号和密码是否正确
2. 检查是否能正常访问 https://jwxt.zjjhkm.edu.cn/jwglxt/
3. 查看 `logs/qiangke.log` 了解详细错误信息
4. 运行 `python main.py test` 单独测试登录

### 课程查询失败
1. 确认课程ID是否正确
2. 选课系统可能尚未开放（程序会自动等待）
3. 检查 `COURSE_QUERY_URL` 配置是否需要修改

### 需要调整API地址
不同学校的正方系统 API 地址可能略有不同：
1. 登录教务系统 → 进入选课界面
2. F12 → Network → 执行选课操作
3. 查看请求的 URL，更新到 `.env` 文件中
